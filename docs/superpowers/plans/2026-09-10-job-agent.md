# Job Agent 实现计划

> **For the main agent:** Implement this plan directly in the current session. Do not dispatch implementation or code-review subagents. After all development tasks are complete, run the affected unit tests and fix any failures before reporting completion. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 单机单用户智能应聘 CLI：多招聘网站登录态复用抓取 → 逐日快照 → 趋势分析 → 结合个人经历的匹配/学习/进阶/趋势建议 → Markdown 日报。

**Architecture:** 确定性 workflow 主干（scrape→normalize→store→match→analyze→advise→report），LLM 仅作为三个分析节点的可选增强（OpenAI 兼容 API），无 LLM 时规则降级。设计文档：`docs/superpowers/specs/2026-09-10-job-agent-design.md`。

**Tech Stack:** Python 3.13 + uv，Playwright(sync, Chromium)，SQLite(stdlib sqlite3)，PyYAML，httpx，pytest。

## Global Constraints

- 依赖仅限：playwright、pyyaml、httpx（运行时）；pytest（开发）。不引入 langgraph/langchain。
- 岗位字段缺失一律存 NULL/空列表，绝不抛错中断；单站点失败不影响整体。
- 所有日期用本地时区 `YYYY-MM-DD` 字符串。
- 包名 `job_agent`，CLI 名 `job-agent`，入口 `python -m job_agent`。
- 数据目录 `data/`（db、auth、html dumps）与 `output/`（日报）均 gitignore。
- 配置：`config/config.example.yaml`、`config/profile.example.yaml` 入库；`init` 复制为真实配置（gitignore）。

### Task 2: models.py + db.py

**Interfaces (produces):**
```python
@dataclass Job: site,title,company,url; job_id(默认 sha1(site+url)[:16]); company_size,industry,salary_text,salary_min(K/月),salary_max,city,district,address,experience_text,experience_min,experience_max,education: str|float|None; responsibilities,requirements_extra,skills: list[str]; urgency,urgency_reason,posted_text,hr_name: str|None; views,greets: int|None; raw: dict
class DB(path):
    upsert_job(job: Job, distance_km: float|None, date: str) -> None   # jobs 表 upsert + job_daily 当日 active 行（幂等）
    record_keyword(date,keyword,site,total_count); record_run(date,site,keyword,count,status,error)
    mark_missing(date) -> int      # 今日无快照的已知 job 记 missing
    query(sql, params) -> list[sqlite3.Row]
    active_job_ids(date) -> set[str]
    geocode_get/put(address,lat,lng)
```
建表 SQL（5 表）：`jobs(job_id PK, site,title,company,company_size,industry,salary_text,salary_min,salary_max,city,district,address,experience_text,experience_min,experience_max,education,responsibilities,requirements_extra,skills,urgency,url,first_seen,last_seen,extra)`；`job_daily(date,job_id,status,salary_min,salary_max,views,greets,distance_km, PK(date,job_id))`；`keywords_daily(date,keyword,site,total_count,PK(date,keyword,site))`；`runs(date,ts,site,keyword,count,status,error)`；`geocode_cache(address PK,lat,lng)`。
**Tests** `test_db.py`: 同一 job upsert 两次不重复、first_seen 不变、last_seen 更新；mark_missing 将历史 job 今日记 missing；distance_km 持久化。

### Task 3: normalize.py

**Interfaces:**
```python
parse_salary(text) -> (min,max)  # K/月
parse_experience(text) -> (min,max)  # 年
parse_education(text) -> str|None  # 归一：不限/大专/本科/硕士/博士
parse_count(text) -> int|None     # "1.2万"→12000
extract_skills(text, vocab) -> list[str]
detect_urgency(title, jd_text, posted_text) -> (level|None, reason)
parse_city_district(text, home_city) -> (city|None, district|None)
DEFAULT_SKILL_VOCAB: list[str]  # 内置常见技术栈词典 ~120 词
```
薪资格式：`25-40K`、`25-40K·16薪`（月 K）、`2-4万`（×10）、`20-35万/年`（÷12 保留 1 位）、`300-500元/天`（×21.75÷1000）、`面议`→(None,None)。
**Tests** 覆盖以上全部格式 + 边界（空/乱文本返回 None）。

### Task 4: distance.py + districts.json

**Interfaces:**

```python
haversine_km(lat1,lng1,lat2,lng2) -> float
```

### Task 5: browser.py + sites/base.py

**Interfaces:**
```python
class BrowserSession:  # context manager
    __init__(config, headless_override=None); open(site_id) -> Page; save_state(site_id); close()
def login_flow(site_id, config) -> None   # 有头打开 login_url，等用户登录+回车，存 data/auth/<site>.json
class BaseSite(ABC):
    site_id,name,login_url: str
    logged_in(page) -> bool
    extract(page, keyword, max_cards) -> tuple[list[dict], int]     # DOM→原始 dict 列表 + 搜索总数
    parse_card_dict(d: dict) -> Job                                  # 纯函数，可测
    detail(page, job) -> Job                                         # 默认原样返回
REGISTRY: dict[str, type[BaseSite]]; get_site(site_id) -> BaseSite
def scrape_all(config, db, sites=None) -> dict   # 遍历站点×关键词：logged_in 检查→extract→parse→normalize→distance→db；返回统计
```
`parse_card_dict` 输入键约定（缺省 None）：`title,company,url,salary,experience,education,city_text,address,company_size,industry,responsibilities,requirements,views_text,greets_text,hr,posted`。dict→Job 时调用 normalize。
**Tests** `test_sites.py`: 每站点 parse_card_dict 用 2 组真实格式样例 dict 断言字段解析。

### Task 7: match.py

**Interfaces:**
```python
@dataclass MatchResult: job,score:float,passed:bool,reasons:list[str]
def filter_and_score(jobs, rules: dict, profile: dict) -> list[MatchResult]
```
硬过滤：exclude_keywords 命中 title/company；salary_max < rules.salary_min；cities 非空且 job.city 不在；education_allow 非空且 job.education 不在；max_distance_km 且 distance 超限；experience_min > rules.experience_max。评分(100)：薪资中点/期望 30、距离 20（<=5km 满分线性衰减）、技能重合 30（∩/profile.skills）、经验贴合 20。
**Tests**: 通过/被各硬条件淘汰各 1 例；评分排序正确。

### Task 9: advisor.py

**Interfaces:**
```python
@dataclass AdvisorReport: match_notes: dict[str,str]; learning: list[str]; level_up: list[str]; trends: list[str]; llm_used: bool
def llm_chat(llm_cfg, system, user, timeout) -> str|None   # POST {base_url}/chat/completions，任何异常→None
def advise(db, config, profile, matches, analysis) -> AdvisorReport
```

**Tests**: fallback_advice 断言缺口计算；llm_chat 用 monkeypatch httpx 断言超时/异常返回 None；advise 在 enabled=False 时走 fallback。
